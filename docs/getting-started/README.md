# 최초 설치

이 디렉터리는 기존 단일 노드나 LVM 데이터를 이전하지 않고 `cloud01`~`cloud03`을 처음부터
구축하는 실행 순서를 담는다.

| 문서 | 용도 |
| --- | --- |
| [3노드 설치 런북](installation.md) | Ubuntu seed부터 Ceph, Kolla OpenStack, management Kubernetes까지 순서대로 실행 |

설치 중 세부 조건이 필요하면 런북이 연결하는 `architecture/`와 `operations/` 문서를 읽는다.
특정 명령만 골라 먼저 실행하지 않는다.
